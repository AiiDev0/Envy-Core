# 🛡️ Envy-Core — Security Suite for Environment Variables (Node.js)

**El validador y auditor de seguridad de variables de entorno definitivo para Node.js.**

> ⚠️ **Nota:** Este repositorio es una vitrina de presentación. El código fuente PRO es privado y se distribuye a través de Gumroad.

## 🎯 El Problema
La mayoría de los hackeos ocurren por contraseñas débiles o variables de desarrollo expuestas en producción. Validar esto manualmente es tedioso y propenso a errores.

## 💡 La Solución
**Envy-Core** es una suite de herramientas CLI que te protege:
- **Gratis (NPM):** Valida tipos, genera `env.d.ts` para TypeScript y crea `.env.example` automáticos.
- **PRO (Gumroad):** Audita la seguridad de tus secretos, encripta tu `.env` con AES-256, bloquea el arranque en producción si detecta `localhost` y escanea tu historial de Git en busca de fugas.

## 🛠️ Tecnologías
Node.js · TypeScript · Commander.js · Chalk · Crypto (AES-256)
